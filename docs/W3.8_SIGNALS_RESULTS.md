# W3.8 Per-Thread Signals and Mask Checkpoint — 2026-10-06

AzamiOS now implements Linux-compliant per-thread signal handling, including independent thread signal masks (`pthread_sigmask` / `rt_sigprocmask`), directed thread signaling (`tkill`, `tgkill`, `rt_tgsigqueueinfo`), per-thread vs process pending signal queues, per-thread alternate signal stack state (`sigaltstack`), and synchronous signal waiting (`sigsuspend`, `rt_sigtimedwait`).

---

### 1. Architectural Changes & Semantics

1. **Independent Per-Thread Signal Masks (`pthread_sigmask` / `rt_sigprocmask`):**
   - Added `sigset_t sig_blocked` to `struct thread` in `kernel/sched/sched.h`.
   - `sys_rt_sigprocmask_impl` operates on and updates the calling thread's `thread->sig_blocked` (and syncs to `proc->sig_blocked` for single-threaded consistency).
   - `SIGKILL` and `SIGSTOP` cannot be blocked and are unconditionally cleared from blocked sets.
   - Thread isolation verified: sibling threads concurrently blocking distinct signal sets (e.g., thread A blocking `SIGUSR1` and thread B blocking `SIGUSR2`) maintain strictly independent masks.

2. **Directed Thread Signaling (`tkill`, `tgkill`, `rt_tgsigqueueinfo`):**
   - Implemented `sched_kill_thread_permitted(caller, tgid, tid, sig)` in `kernel/sched/sched.c`:
     - Strict argument validation: rejects `tid <= 0`, `tgid < 0`, and invalid signal numbers with `-EINVAL`.
     - Validates thread group membership: returns `-ESRCH` if `tgid > 0` does not match the target thread's owning process, or if `tid` does not exist.
     - POSIX signal 0 permission probing: returns 0 if target exists and caller has permission (`CAP_KILL` or matching real/effective UID).
     - Job-control redirection: `SIGSTOP`, `SIGTSTP`, `SIGTTIN`, `SIGTTOU`, `SIGCONT` operate on the process as a whole per POSIX specifications.
     - Directed queuing: if the target thread blocks the signal, it is queued specifically onto `target_thread->sig_pending` and will not be delivered to sibling threads.
     - Wakeup: if the target thread is asleep in an interruptible wait, wakes the target thread immediately.

3. **Per-Thread vs Process-Wide Pending Queues (`sigpending` / `rt_sigpending`):**
   - Added `sigset_t sig_pending` to `struct thread`.
   - `sys_rt_sigpending_impl` reports `(proc->sig_pending | thread->sig_pending) & thread->sig_blocked`.
   - Thread isolation verified: a signal directed to thread B via `tgkill` is reported as pending in thread B's `sigpending`, but is invisible in thread A's `sigpending`.
   - Shared signal consumption verified: a process-directed signal (`kill(pid, sig)`) is visible to all threads that block it; once any unblocked thread delivers and consumes the signal, it is atomically removed from `proc->sig_pending` and disappears from all sibling threads' pending masks.

4. **Per-Thread Alternate Signal Stacks (`sigaltstack`):**
   - Added `sas_ss_sp`, `sas_ss_size`, and `sas_ss_flags` to `struct thread`.
   - Each thread created via `pthread_create` (`CLONE_VM | CLONE_THREAD`) begins with alternate stack disabled (`SS_DISABLE`), maintaining strict thread independence.
   - Validates configuration: enforces minimum stack size (`MINSIGSTKSZ = 2048`, returning `-ENOMEM` if smaller), rejects undefined flag bits with `-EINVAL`, and validates user pointers with `-EFAULT`.
   - Active onstack execution guard: when delivering a signal configured with `SA_ONSTACK`, the kernel enters the handler on the alternate stack and flags `SS_ONSTACK`. Any attempt to modify the alternate stack while actively executing on it returns `-EPERM`.

5. **Inheritance & Process Lifecycle:**
   - `clone()`: child inherits calling thread's `sig_blocked`. Pending signals are never inherited (`sig_pending = 0`). For child processes, alternate stack is copied with `SS_ONSTACK` cleared; for child threads (`CLONE_THREAD`), alternate stack is reset to `SS_DISABLE`.
   - `execve()`: preserves `sig_blocked`, clears pending signals, and resets alternate signal stack to `SS_DISABLE`.

6. **Synchronous Signal Suspension & Waiting (`sigsuspend`, `rt_sigtimedwait`):**
   - `sys_rt_sigsuspend_impl` sets a temporary mask on `thread->sig_blocked`, arms `thread->restore_signal_mask`, delivers the signal, returns `-EINTR`, and restores the previous mask.
   - `sys_rt_sigtimedwait_impl` checks both `thread->sig_pending` and `proc->sig_pending`, consumes the matched signal, fills `siginfo_t` (`si_signo`), and returns `-EAGAIN` on timeout if nothing is pending.

7. **VFS & Subsystem Compatibility (`epoll_pwait`, `signalfd`):**
   - `epoll_masked_wait` in `kernel/syscall/sys_fs.c` temporarily applies masks to `thread->sig_blocked` rather than process-wide masks, ensuring multi-threaded `epoll_pwait` / `epoll_pwait2` calls do not interfere with sibling threads.
   - `signalfd` read and poll operations inspect and consume from both `thread->sig_pending` and `proc->sig_pending`.
