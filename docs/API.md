# AzamiOS API Reference

This document is automatically generated by `scripts/autodoc.py` from `/** ... */` comments in header files.

## `arch/x86_64/cpu/gdt.h`

- **`gdt_init_bsp()`**: Initialise the GDT and TSS for the bootstrap processor. Called once from kernel_main() before interrupts are enabled. Automatically reads the current RSP and uses it as the initial RSP0.
- **`gdt_init_ap(core_id, kernel_stack_top)`**: Initialise GDT/TSS for an AP core. Called from the AP trampoline (smp.c) for each application processor. @core_id          APIC ID of this core (0 < core_id < HAL_MAX_CPUS). @kernel_stack_top Top of the AP's dedicated kernel stack (RSP0).
- **`gdt_set_rsp0(core_id, stack_top)`**: Update TSS.RSP0 for the given core. Must be called on every context switch to ensure the next ring-0 entry (interrupt, syscall) uses the correct kernel stack for the new thread.
- **`gdt_set_ist(core_id, index, stack_top)`**: Set an IST stack pointer. @index  1–7 (IST1 through IST7).

## `arch/x86_64/cpu/idt.h`

- **`idt_init()`**: Populate all 256 IDT entries and load the IDTR.
- **`idt_set_gate()`**: Install a single IDT gate. @vector   Interrupt vector (0–255). @handler  64-bit address of the ISR stub. @ist      IST index (0 = use current RSP, 1–7 = IST stack from TSS). @dpl      Descriptor Privilege Level (0 = kernel-only, 3 = user callable). @type     IDT_TYPE_INT_GATE or IDT_TYPE_TRAP_GATE.

## `arch/x86_64/cpu/lapic.h`

- **`lapic_init()`**: Map LAPIC MMIO, enable APIC via SVR, disable PIC.
- **`lapic_eoi()`**: Signal End-Of-Interrupt to the local APIC.
- **`lapic_id()`**: Return the LAPIC ID of the calling CPU.
- **`lapic_timer_calibrate()`**: Calibrate LAPIC timer against PIT/TSC.
- **`lapic_timer_start(hz)`**: Start periodic timer at the given frequency.
- **`lapic_timer_stop()`**: Stop the LAPIC timer.
- **`lapic_send_ipi(lapic_id, vector)`**: Send a fixed IPI to one APIC.
- **`lapic_send_sipi(lapic_id, trampoline_page)`**: Send Startup IPI to AP.
- **`lapic_send_init(lapic_id)`**: Send INIT IPI to AP.
- **`lapic_base_phys()`**: Return the physical base address of the LAPIC MMIO.

## `arch/x86_64/cpu/pic.h`

- **`pic_init(offset1, offset2)`**: Remap both PICs to the given vector offsets. On x86 the PIC starts at vectors 8 (IRQ0) and 70 (IRQ8) — colliding with CPU exceptions. We remap them to offset1=32 (IRQ0→vec32) and offset2=40. After an LAPIC is initialised, the PICs are masked entirely.
- **`pic_mask_all()`**: Mask all IRQ lines on both PICs (used after LAPIC init).
- **`pic_eoi(irq)`**: Send End-Of-Interrupt to the relevant PIC.
- **`pic_set_mask(irq) / pic_clear_mask(irq)`**: Mask or unmask a single IRQ.

## `arch/x86_64/cpu/smp.h`

- **`struct cpu_info`**: Per-CPU data structure stored in GS segment. GS.base points directly to the start of this structure for current CPU.
- **`smp_init()`**: Initialize per-CPU structures and boot Application Processors.
- **`smp_get_cpu()`**: Get pointer to cpu_info_t for the current CPU via GS.
- **`smp_current_cpu_id()`**: Return logical CPU ID of the calling CPU.
- **`smp_cpu_count()`**: Return total number of online CPUs.
- **`smp_send_reschedule(cpu_id)`**: Send IPI to force rescheduling on a remote CPU.

## `arch/x86_64/cpu/spinlock.h`

- **`spinlock_lock(lock)`**: Acquire the spinlock (busy-wait with pause). Does NOT save or modify interrupt flags.
- **`spinlock_unlock(lock)`**: Release the spinlock.
- **`spinlock_lock_irqsave(lock)`**: Disable interrupts, then acquire the lock. Returns the previous RFLAGS value (use with spinlock_unlock_irqrestore).
- **`spinlock_unlock_irqrestore(lock, flags)`**: Release the lock, restore RFLAGS.
- **`spinlock_try_lock(lock)`**: Non-blocking attempt. Returns true if acquired.

## `arch/x86_64/mm/vmm.h`

- **`vmm_init()`**: Set up the kernel's canonical page table. Maps: 1. The kernel ELF (text RX, data/bss RW, rodata R) at -2 GB. 2. The HHDM: all physical RAM at HHDM_BASE. 3. Installs the new CR3 and enables SMEP/SMAP via CR4. @hhdm_base   HHDM virtual address reported by Limine. @phys_base   Physical base address of the loaded kernel. @virt_base   Virtual base address of the loaded kernel. @memmap      Limine memory-map response (to enumerate RAM for HHDM).
- **`vmm_map(space, virt, phys, flags)`**: Map one 4 KB page. Creates intermediate page table levels as needed (allocating from PMM). @space   PML4 physical address (or 0 for the kernel address space). @virt    Virtual address (must be 4 KB aligned). @phys    Physical address (must be 4 KB aligned). @flags   Combination of VMM_F_* flag bits. Returns 0 on success, -1 on allocation failure.
- **`vmm_unmap(space, virt)`**: Unmap one 4 KB page and invalidate the TLB entry.
- vmm_translate(space, virt) → physical address, or 0 if not mapped.
- **`vmm_create_space()`**: Allocate a new page table and copy the kernel half. PML4 indices 256–511 (kernel half) are shared with the kernel's PML4. PML4 indices 0–255 (user half) start empty. Returns the physical address of the new PML4, or 0 on failure.
- **`vmm_clone_space(src)`**: Deep-copy the user half of an address space. Copies all user PML4 entries (0–255) and all subordinate page tables. Physical pages with the WRITE flag set are duplicated (copy-on-write is a future enhancement; for now full copy). Returns new PML4 physical address, or 0 on failure.
- **`vmm_destroy_space(space)`**: Free all user-space page tables and physical pages.
- **`vmm_switch(space)`**: Load the given PML4 into CR3 (switches address space).
- **`vmm_kernel_space()`**: Returns the physical address of the kernel's PML4.
- **`vmm_map_io(phys, size)`**: Map physical MMIO/IO range and return virtual address.

## `kernel/mm/kmalloc.h`

## `kernel/mm/pmm.h`

- **`pmm_init()`**: Initialise the physical memory manager. Reads the Limine memory map to discover usable physical memory ranges, then populates the buddy free lists. Must be called before any pmm_alloc(). @memmap   Pointer to the Limine memory-map response structure. (Typed as void* to avoid pulling limine.h into every consumer.)
- pmm_alloc(order) → physical address of the allocated block, or 0 on failure. Allocates a naturally aligned, contiguous physical memory block of (1 << order) × PAGE_SIZE bytes. @order   0–PMM_MAX_ORDER.
- **`pmm_free(phys, order)`**: Return a block to the buddy free list. @phys    Physical address of the block (must be naturally aligned to the block's size: phys % (PAGE_SIZE << order) == 0). @order   Must match the order passed to pmm_alloc().
- **`Convenience wrappers for single`**: page allocation (order 0).
- **`Multi`**: page allocation helper (calculates required order automatically).

## `kernel/sched/sched.h`

- **`struct thread`**: Microkernel execution unit.
- **`struct process`**: Microkernel address space and resource container.
- **`sched_init()`**: Initialize CFS scheduler and per-CPU idle threads.
- **`sched_start()`**: Start scheduling on current CPU (does not return).
- **`sched_tick(regs)`**: Handle LAPIC timer tick, update vruntime, and preempt if necessary.
- **`sched_yield()`**: Voluntarily yield CPU to the next ready thread.
- **`sched_check_reschedule()`**: Check and perform deferred reschedule (call from IRQ return path).
- **`sched_block(new_state)`**: Block current thread until unblocked.
- **`sched_sleep(ticks)`**: Put current thread to sleep for specified tick count.
- **`sched_waitpid(target_pid, status, options)`**: Wait for child process termination.
- **`sched_unblock(t)`**: Mark a blocked/sleeping thread as READY.
- **`sched_current_thread()`**: Return pointer to current thread on calling CPU.
- **`sched_current_process()`**: Return pointer to current process on calling CPU.
- **`proc_create(name, pml4_phys)`**: Create a new process container.
- **`proc_destroy(proc)`**: Unlink and free process container.
- **`thread_create(proc, entry, arg, is_kernel)`**: Create a new execution thread.
- **`sched_exit_thread()`**: Terminate current thread and reschedule (never returns).
- **`sched_kill_process(pid, sig)`**: Send signal to process or terminate it.
- **`sched_get_process_list()`**: Return head of global process list.

## `kernel/security/security.h`

- **`security_init()`**: Initialize stack canaries and security boundaries.
- **`security_validate_user_ptr(ptr, size)`**: Verify pointer is within ring-3 space.
- **`security_validate_kernel_ptr(ptr, size)`**: Verify pointer is in higher-half space.
- **`security_check_permission(proc, capability)`**: Check capability bits on a process.

## `kernel/syscall/syscall.h`

- **`syscall_dispatch()`**: Main C-side syscall handler. Called from syscall_entry.asm with the full register frame. Return value is placed in regs->rax by this function.
- **`sys_exit_impl()`**: Exit current process and free resources.
- **`syscall_init()`**: Register all syscall handlers. Called from kernel_main() after the scheduler is up.

## `kernel/uaccess.h`

- **`user_access_begin()`**: Temporarily allow kernel access to user space (STAC).
- **`user_access_end()`**: Re-enable kernel protection against user access (CLAC).
- **`copy_from_user(dst, src, size)`**: Safely copy memory from user space. @dst  Kernel destination buffer. @src  User source buffer. @size Number of bytes to copy. Returns the number of bytes that could NOT be copied (0 on success).
- **`copy_to_user(dst, src, size)`**: Safely copy memory to user space. @dst  User destination buffer. @src  Kernel source buffer. @size Number of bytes to copy. Returns the number of bytes that could NOT be copied (0 on success).
- **`search_extable(ip)`**: Search the exception table for a faulting instruction. @ip   The instruction pointer (RIP) that caused the page fault. Returns the fixup address if found, or 0 if not found.

## `userland/libc/include/az/ipc.h`

- **`az_channel_create()`**: Create a new IPC channel. Returns channel ID or negative errno.
- **`az_channel_send(channel_id, msg)`**: Send a message (blocking). Returns 0 or negative errno.

- **`az_shmem_unmap(shmem_id, virt_addr)`**: Unmap shared memory from this process. Returns 0 or negative errno.
- **`az_shmem_destroy(shmem_id)`**: Destroy shared memory region. Returns 0 or negative errno.
- **`az_fb_info(info)`**: Get framebuffer dimensions. Returns 0 or negative errno.
- **`az_fb_map(virt_addr)`**: Map the hardware framebuffer at the given address. Returns 0 or negative errno.

- **`az_yield()`**: Voluntarily yield CPU.
- **`az_sleep(ms)`**: Sleep for specified milliseconds.
